# Minimal Themed React App

1. Run `npm create vite@latest my-app -- --template react` and `cd my-app`.
2. Install deps: `npm install react react-dom react-router-dom clsx web-vitals`.
3. Install dev deps: `npm install -D tailwindcss postcss autoprefixer` and `npx tailwindcss init -p`.
4. Replace config and src files with this scaffold, keep existing bundler devDependencies.
5. Run `npm run dev` and open `/settings` to change theme and `/view` to preview.
